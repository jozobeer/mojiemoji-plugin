# Mojiemoji Github (Claude)

## トリガーとスコープ

ユーザーが GitHub surface 向けの mojiemoji スニペットを欲しているときだけ起動する。Slack のカスタム絵文字、Notion、一般的な Web ページには起動しない — ここで規定するデフォルトはすべて GitHub のサニタイザを<img src="https://mojiemoji.jozo.beer/emoji/%E5%89%8D?font=dela&amp;color=f87171&amp;animation=ekken&amp;background=transparent&amp;outline=26dc26&amp;outline_width=2" alt="前" height="24" align="absmiddle">提にしている。

### 発火する surface(完全列挙)

以下のいずれかで<img src="https://mojiemoji.jozo.beer/emoji/%E6%97%A5?font=tamanegi&amp;color=f87171&amp;animation=kage_neon&amp;background=transparent&amp;outline=26dc26&amp;outline_width=2" alt="日" height="24" align="absmiddle">本語 body を提出する<img src="https://mojiemoji.jozo.beer/emoji/%E5%89%8D?font=chikara&amp;color=ec4899&amp;animation=poyoon&amp;background=transparent&amp;outline=99ec48&amp;outline_width=2" alt="前" height="24" align="absmiddle">に、`mojiemoji-github` skill による装飾を行う:

- `gh` CLI 投稿系: `gh issue create` / `gh issue comment` / `gh issue edit` / `gh pr create` / `gh pr comment` / `gh pr review` / `gh pr edit` / `gh release create` / `gh release edit`
- raw GitHub REST: `gh api .../pulls/.../reviews` / `gh api .../pulls/.../comments` / `gh api .../issues/.../comments` / `gh api .../issues` 等(`--input` payload や `-F body=...` も<img src="https://mojiemoji.jozo.beer/emoji/%E5%AF%BE%E8%B1%A1?font=gothic-bold&amp;color=f97316&amp;animation=gatagata&amp;background=transparent&amp;outline=16f973&amp;outline_width=2" alt="対象" height="24" align="absmiddle">)
- MCP GitHub ツール経路: `mcp__*__github_create_pull_request` / `github_add_issue_comment` / `github_pull_request_review_write` / `github_issue_write` / `github_update_pull_request` / `github_add_comment_to_pending_review` / `github_add_reply_to_pull_request_comment` 等
- subagent 駆動の一括投稿: `cross-repo-review` / `triage-review` / `vibes-review` / `copilot-review` 等が複数 <img src="https://mojiemoji.jozo.beer/emoji/PR?font=toge&amp;color=3b82f6&amp;animation=zairu&amp;background=transparent&amp;outline=f63b82&amp;outline_width=2" alt="PR" height="24" align="absmiddle"> を回って review/comment を連投する経路
- 上記いずれでもない新経路でも、<img src="https://mojiemoji.jozo.beer/emoji/%E6%97%A5?font=tamanegi&amp;color=f87171&amp;animation=kage_neon&amp;background=transparent&amp;outline=26dc26&amp;outline_width=2" alt="日" height="24" align="absmiddle">本語 GitHub body を提出するなら例外なく<img src="https://mojiemoji.jozo.beer/emoji/%E5%AF%BE%E8%B1%A1?font=gothic-bold&amp;color=f97316&amp;animation=gatagata&amp;background=transparent&amp;outline=16f973&amp;outline_width=2" alt="対象" height="24" align="absmiddle">

Claude Code では最終 gate として PreToolUse hook (`hooks/mojiemoji_japanese_gate.py`) が submission <img src="https://mojiemoji.jozo.beer/emoji/%E7%9B%B4%E5%89%8D?font=kurobara&amp;color=fbbf24&amp;animation=poyoon&amp;background=transparent&amp;outline=06d977&amp;outline_width=2" alt="直前" height="24" align="absmiddle">に発火し、未装飾の<img src="https://mojiemoji.jozo.beer/emoji/%E6%97%A5?font=maru-bold&amp;color=d946ef&amp;animation=yatta&amp;background=transparent&amp;outline=efd946&amp;outline_width=2" alt="日" height="24" align="absmiddle">本語 body を block する。Codex package では hook gate はインストールされないため、`prestamp.py` とこの skill の手順が実質の gate になる。Skill を先に呼んでおけば hook 対応ハーネスでも再装飾のラウンドトリップが<img src="https://mojiemoji.jozo.beer/emoji/%E7%99%BA%E7%94%9F?font=mincho&amp;color=ec4899&amp;animation=gatagata&amp;background=transparent&amp;outline=99ec48&amp;outline_width=2" alt="発生" height="24" align="absmiddle">しない、というのが skill 側で gate を<img src="https://mojiemoji.jozo.beer/emoji/%E5%AE%9F%E8%A3%85?font=chikara&amp;color=ef4444&amp;animation=zanzo&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="実装" height="24" align="absmiddle">する意義。

### <img src="https://mojiemoji.jozo.beer/emoji/UX?font=toge&amp;color=c084fc&amp;animation=yatta&amp;background=transparent&amp;outline=fcc084&amp;outline_width=2" alt="UX" height="24" align="absmiddle"> ルール — メニューを出さず、装飾して見せる

3. **Wait for yes/no** — 「これで投稿してよい?」の<img src="https://mojiemoji.jozo.beer/emoji/%E7%A2%BA%E8%AA%8D?font=noto&amp;color=fb7185&amp;animation=mochimochi&amp;background=transparent&amp;outline=85fb71&amp;outline_width=2" alt="確認" height="24" align="absmiddle">だけ取る。<img src="https://mojiemoji.jozo.beer/emoji/%E4%BF%AE%E6%AD%A3?font=gothic-bold&amp;color=ef4444&amp;animation=kirari&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="修正" height="24" align="absmiddle">要求があれば 1 に戻る

`mojiemoji-selector` subagent にデリゲートする場合も<img src="https://mojiemoji.jozo.beer/emoji/%E5%90%8C%E6%A7%98?font=gothic&amp;color=f59e0b&amp;animation=poyoon&amp;background=transparent&amp;outline=0bf59e&amp;outline_width=2" alt="同様" height="24" align="absmiddle"> — selector が返した snippet を本文に embed して draft を<img src="https://mojiemoji.jozo.beer/emoji/%E7%94%9F%E6%88%90?font=dela&amp;color=fb923c&amp;animation=ekken&amp;background=transparent&amp;outline=0cea58&amp;outline_width=2" alt="生成" height="24" align="absmiddle">させ、その draft をユーザーに見せる(selector の生 output を user に見せて「どれにします?」と聞かない)。

### Reviews <img src="https://mojiemoji.jozo.beer/emoji/API?font=mincho&amp;color=10b981&amp;animation=patapata&amp;background=transparent&amp;outline=8110b9&amp;outline_width=2" alt="API" height="24" align="absmiddle"> の surface policy(`body` + `comments[]`)

## デフォルトのトーンとインライン飽和

ユーザーがトーンを指定しない場合、surface ごとのデフォルトは**全 surface とも loud(インライン飽和)** — issue / <img src="https://mojiemoji.jozo.beer/emoji/PR?font=toge&amp;color=3b82f6&amp;animation=zairu&amp;background=transparent&amp;outline=f63b82&amp;outline_width=2" alt="PR" height="24" align="absmiddle"> 本文 / リリースノート / レビュー本文 / レビュー返信 / Issue・<img src="https://mojiemoji.jozo.beer/emoji/PR?font=maru&amp;color=34d399&amp;animation=gatagata&amp;background=transparent&amp;outline=9934d3&amp;outline_width=2" alt="PR" height="24" align="absmiddle"> コメント、いずれも本文と<img src="https://mojiemoji.jozo.beer/emoji/%E5%90%8C%E3%81%98?font=hachimaru&amp;color=f472b6&amp;animation=yurayura&amp;background=transparent&amp;outline=b6f472&amp;outline_width=2" alt="同じ" height="24" align="absmiddle">密度で装飾する。ただし <img src="https://mojiemoji.jozo.beer/emoji/PR?font=hachimaru&amp;color=ef4444&amp;animation=bure&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="PR" height="20" align="absmiddle"> body は repo policy gate が先で、commit message に <img src="https://mojiemoji.jozo.beer/emoji/PR?font=maru&amp;color=34d399&amp;animation=gatagata&amp;background=transparent&amp;outline=9934d3&amp;outline_width=2" alt="PR" height="20" align="absmiddle"> body が流れる repository では既定 skip。違うのは*block* の使用可否だけ — レビュー surface には block スロットが<img src="https://mojiemoji.jozo.beer/emoji/%E5%AD%98%E5%9C%A8?font=dela&amp;color=f472b6&amp;animation=neruneru&amp;background=transparent&amp;outline=77db27&amp;outline_width=2" alt="存在" height="24" align="absmiddle">せず、body surface でもユーザーがそのターン内で明示的に block 装飾を依頼した場合に限る。ユーザーが「calm にして」「軽めで」「控えめに」と明示した場合、または本文が「装飾してはいけない」カテゴリ(謝罪 / セキュリティ / 法務 / コンプライアンス / 受け入れ基準を単独で見せるケース)である場合のみオーバーライドする。本文で迷ったら loud を選ぶこと。

**「loud」とは、段落・箇条書きすべてに渡るインライン密度のこと**であり、大きな block スタンプではない。ユーザーの明示的な好み(<img src="https://mojiemoji.jozo.beer/emoji/%E3%82%AD%E3%83%BC?font=chikara&amp;color=a855f7&amp;animation=yoko_scroll&amp;background=transparent&amp;outline=f7a855&amp;outline_width=2" alt="キー" height="24" align="absmiddle">ワード列挙・例外なし):

- ✓ **常にインライン埋め込み**で、文中の単語を置き換える。密度は惜しみなく — 1 段落あたり最低 1〜2 個、アイデアの濃い箇条書きならもっと多く。文法的に収まる名詞・動詞・副詞はすべて埋め込む。
- ✗ **セクション末のオチ装飾**(各セクションの<img src="https://mojiemoji.jozo.beer/emoji/%E5%BE%8C?font=hachimaru&amp;color=f472b6&amp;animation=nami&amp;background=transparent&amp;outline=b6f472&amp;outline_width=2" alt="後" height="24" align="absmiddle">ろに `→ <stamp1> <stamp2>` を独立行で置く)は**使わない**。
- ✗ **締めの装飾**(本文末に `---` + 独立行のムードスタンプ)も**使わない**。
- ✓ **文末・段落末・見出し末の trailing 装飾**は 2 段階<img src="https://mojiemoji.jozo.beer/emoji/%E5%84%AA%E5%85%88?font=akzk&amp;color=22d3ee&amp;animation=mochimochi&amp;background=transparent&amp;outline=b20891&amp;outline_width=2" alt="優先" height="24" align="absmiddle">で選ぶ(catalog 在の絵文字は mojiemoji 化、未登録は素の Unicode)。<img src="https://mojiemoji.jozo.beer/emoji/%E8%A9%B3%E7%B4%B0?font=maru&amp;color=ef4444&amp;animation=yoko_scroll&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="詳細" height="24" align="absmiddle">は `references/trailing-decoration.md` を<img src="https://mojiemoji.jozo.beer/emoji/%E5%8F%82%E7%85%A7?font=mincho&amp;color=60a5fa&amp;animation=tate_scroll&amp;background=transparent&amp;outline=eb2563&amp;outline_width=2" alt="参照" height="24" align="absmiddle">。

**マントラ**: 「文中に埋める」「文法崩壊しないように自然に埋め込みまくる」。密度は高く*かつ*文法は自然に保つ — どの埋め込みもクリーンな単語<img src="https://mojiemoji.jozo.beer/emoji/%E7%BD%AE%E6%8F%9B?font=pixel&amp;color=ef4444&amp;animation=kirari&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="置換" height="24" align="absmiddle">として読めること、関係ない品詞の間にぎこちなく突っ込まれていないこと。文法的に自然なスロットが無い候補なら、そのフレーズはスタンプせずに諦める。

**INTENSITY（`prestamp.py --intensity`）** は **TONE（calm / neutral / loud）とは直交**する軸で、機械<img src="https://mojiemoji.jozo.beer/emoji/%E7%BD%AE%E6%8F%9B?font=hachimaru&amp;color=facc15&amp;animation=norinori&amp;background=transparent&amp;outline=04ca8a&amp;outline_width=2" alt="置換" height="24" align="absmiddle">のボリュームだけを下げます。既定は `aggressive`（従来互換）。抑えたいときは `normal` または `minimal` を CLI で明示してください。`normal` / `minimal` では<img src="https://mojiemoji.jozo.beer/emoji/%E5%87%BA%E5%8A%9B?font=gothic-bold&amp;color=fb7185&amp;animation=yokomoya&amp;background=transparent&amp;outline=85fb71&amp;outline_width=2" alt="出力" height="24" align="absmiddle"><img src="https://mojiemoji.jozo.beer/emoji/%E6%9C%AB%E5%B0%BE?font=tamanegi&amp;color=22d3ee&amp;animation=chirichiri&amp;background=transparent&amp;outline=b20891&amp;outline_width=2" alt="末尾" height="24" align="absmiddle">に `<!-- mojiemoji-intensity:… -->` が<img src="https://mojiemoji.jozo.beer/emoji/%E8%87%AA%E5%8B%95?font=chikara&amp;color=fdba74&amp;animation=norinori&amp;background=transparent&amp;outline=74fdba&amp;outline_width=2" alt="自動" height="24" align="absmiddle">付与され、catalog-leftovers gate が緩いしきい値を<img src="https://mojiemoji.jozo.beer/emoji/%E5%8F%82%E7%85%A7?font=mincho&amp;color=60a5fa&amp;animation=tate_scroll&amp;background=transparent&amp;outline=eb2563&amp;outline_width=2" alt="参照" height="24" align="absmiddle">します。

毎回 `--intensity` を渡したくない場合は **`/mojiemoji-config` skill** で既定の intensity を `~/.config/mojiemoji/config.json` に<img src="https://mojiemoji.jozo.beer/emoji/%E4%BF%9D%E5%AD%98?font=maru-bold&amp;color=f97316&amp;animation=zanzo&amp;background=transparent&amp;outline=16f973&amp;outline_width=2" alt="保存" height="24" align="absmiddle">できます（解決順: CLI > <img src="https://mojiemoji.jozo.beer/emoji/%E8%A8%AD%E5%AE%9A?font=maru-bold&amp;color=f472b6&amp;animation=mochimochi&amp;background=transparent&amp;outline=b6f472&amp;outline_width=2" alt="設定" height="24" align="absmiddle"> > `aggressive`）。

**<img src="https://mojiemoji.jozo.beer/emoji/PR?font=hachimaru&amp;color=ef4444&amp;animation=bure&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="PR" height="20" align="absmiddle"> body policy gate**: `prestamp.py --surface pr-body` と PreToolUse gate は `gh api repos/{owner}/{repo}` の `squash_merge_commit_message` / `merge_commit_message` を見て、`PR_BODY` を使うメソッドが<img src="https://mojiemoji.jozo.beer/emoji/%E6%9C%89%E5%8A%B9?font=noto&amp;color=60a5fa&amp;animation=disco&amp;background=transparent&amp;outline_width=0" alt="有効" height="20" align="absmiddle"> (`allow_squash_merge` / `allow_merge_commit`) なときだけ leaks と判定する。leaks なら本文をそのまま返し、装飾済みの <img src="https://mojiemoji.jozo.beer/emoji/PR?font=maru&amp;color=34d399&amp;animation=gatagata&amp;background=transparent&amp;outline=9934d3&amp;outline_width=2" alt="PR" height="20" align="absmiddle"> body を送ろうとした場合は gate が ブロックする (commit 履歴に HTML が残るため)。取得値は `${XDG_CACHE_HOME:-~/.cache}/mojiemoji/repo-policy/<owner>--<repo>.json` に 1 時間 cache する。cache が壊れている / 期限切れのときは破棄して再取得し、再取得でも policy を判定できない場合 (取得<img src="https://mojiemoji.jozo.beer/emoji/%E5%A4%B1%E6%95%97?font=hachimaru&amp;color=f472b6&amp;animation=mozaiku&amp;background=transparent&amp;outline=b6f472&amp;outline_width=2" alt="失敗" height="20" align="absmiddle"> / gh 未認証 / 非 github remote) に だけ<img src="https://mojiemoji.jozo.beer/emoji/%E5%AE%89%E5%85%A8?font=gothic-bold&amp;color=ec4899&amp;animation=mabataki&amp;background=transparent&amp;outline=99ec48&amp;outline_width=2" alt="安全" height="20" align="absmiddle">側として skip する。どうしても <img src="https://mojiemoji.jozo.beer/emoji/PR?font=hachimaru&amp;color=ef4444&amp;animation=bure&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="PR" height="20" align="absmiddle"> body に mojiemoji を入れる場合だけ `MOJIEMOJI_FORCE_PR_BODY=1` を付ける (Bash は command 先頭、MCP は body 内)。

## 埋め込み vs 装飾(根本<img src="https://mojiemoji.jozo.beer/emoji/%E6%A6%82%E5%BF%B5?font=gothic&amp;color=3b82f6&amp;animation=shuchusen&amp;background=transparent&amp;outline=f63b82&amp;outline_width=2" alt="概念" height="24" align="absmiddle">)

`inline` <img src="https://mojiemoji.jozo.beer/emoji/%E3%83%A2%E3%83%BC%E3%83%89?font=zero&amp;color=60a5fa&amp;animation=yokomoya&amp;background=transparent&amp;outline=eb2563&amp;outline_width=2" alt="モード" height="24" align="absmiddle">の中には**2 つのサブパターン**があり、ソース上は<img src="https://mojiemoji.jozo.beer/emoji/%E5%90%8C%E3%81%98?font=mincho&amp;color=a78bfa&amp;animation=yatta&amp;background=transparent&amp;outline=ed7c3a&amp;outline_width=2" alt="同じ" height="24" align="absmiddle">に見えるがレンダリングされた<img src="https://mojiemoji.jozo.beer/emoji/%E7%B5%90%E6%9E%9C?font=akzk&amp;color=60a5fa&amp;animation=norinori&amp;background=transparent&amp;outline=eb2563&amp;outline_width=2" alt="結果" height="24" align="absmiddle">はまったく違って読める:

| パターン | 何 | <img src="https://mojiemoji.jozo.beer/emoji/%E9%85%8D%E7%BD%AE?font=akzk&amp;color=eab308&amp;animation=bane&amp;background=transparent&amp;outline=08eab3&amp;outline_width=2" alt="配置" height="24" align="absmiddle"> | 文法的役割 |
|---|---|---|---|
| **埋め込み(embed)** | スタンプが文中の単語を置き換える | 文中 | **その文に合う**名詞・動詞・副詞の代わり |
| **装飾(decoration)** | 文法的役割なくムードや勢いを添える | 文の下に独立行、`→` を<img src="https://mojiemoji.jozo.beer/emoji/%E5%89%8D?font=chikara&amp;color=ec4899&amp;animation=poyoon&amp;background=transparent&amp;outline=99ec48&amp;outline_width=2" alt="前" height="24" align="absmiddle">置 | なし — 純粋に装飾 |

**ルール: 散文の文末に装飾スタンプを付け足してはいけない。** 文末の trailing 装飾は埋め込みと視覚的に混ざり、文の終わりが認識できなくなる。trailing 装飾は専用行に移すこと。<img src="https://mojiemoji.jozo.beer/emoji/%E8%A9%B3%E7%B4%B0?font=maru&amp;color=ef4444&amp;animation=yoko_scroll&amp;background=transparent&amp;outline=44ef44&amp;outline_width=2" alt="詳細" height="24" align="absmiddle">・絵文字 trailing decoration の 2 段階<img src="https://mojiemoji.jozo.beer/emoji/%E5%84%AA%E5%85%88?font=pixel&amp;color=f472b6&amp;animation=zanzo&amp;background=transparent&amp;outline=b6f472&amp;outline_width=2" alt="優先" height="24" align="absmiddle">・`%0A` 改行ルールは `references/trailing-decoration.md` を<img src="https://mojiemoji.jozo.beer/emoji/%E5%8F%82%E7%85%A7?font=mincho&amp;color=60a5fa&amp;animation=tate_scroll&amp;background=transparent&amp;outline=eb2563&amp;outline_width=2" alt="参照" height="24" align="absmiddle">。

### スタンプ<img src="https://mojiemoji.jozo.beer/emoji/%E5%AF%BE%E8%B1%A1?font=akzk&amp;color=facc15&amp;animation=disco&amp;background=transparent&amp;outline_width=0" alt="対象" height="24" align="absmiddle">: 文ではなく単語

mojiemoji は**単語レベルの一撃**であって、句や文の強調ではない。スイートスポットは**2 字の漢字熟語(二字熟語)** — コンパクトで意味密度が高く、視覚的にも際立つ。

| スタンプにする | スタンプしない |
|---|---|
| `歓迎` `修正` `確認` `完了` `重要` `緊急` `綺麗` `完璧` `要点` `対応` …(2 字熟語) | `気になりました` `お疲れさまでした`(完全な文 / 述語+丁寧語) |
| `PR` `OK` `NG` `WIP` `API` `LGTM` 等(2〜4 字の ASCII 略語 / ドメイン用語) | `〜していただきありがとうございます`(挨拶ブロック) |
| `マージ` `テスト` `バグ` `リファクタ`(2〜4 字のカタカナ語) | *単語*ではなく*文法的な節*に当たるもの |
| `綺麗` `素敵` `見事` `丁寧`(2 字の形容詞・形容動詞) | 動詞形(`書きました` `送ります` `読んでます`) |

候補テキストが文なら**スタンプ自体を諦める** — 同文の別の単語を選ぶか、その箇所にはスタンプが乗らないと受け入れる。

文字種別ごとのスタンプ長<img src="https://mojiemoji.jozo.beer/emoji/%E4%B8%8A%E9%99%90?font=maru&amp;color=3b82f6&amp;animation=yokomoya&amp;background=transparent&amp;outline=f63b82&amp;outline_width=2" alt="上限" height="24" align="absmiddle">(漢字 ≤2、ひらがな ≤5、カタカナ ≤3、ASCII ≤3)、4 字以上の単語の<img src="https://mojiemoji.jozo.beer/emoji/%E5%88%86%E5%89%B2?font=chikara&amp;color=06b6d4&amp;animation=tate_scroll&amp;background=transparent&amp;outline=d406b6&amp;outline_width=2" alt="分割" height="24" align="absmiddle">ヒューリスティック、`%0A` 改行ルールは `references/parameters.md` § スタンプ<img src="https://mojiemoji.jozo.beer/emoji/%E5%AF%BE%E8%B1%A1?font=akzk&amp;color=facc15&amp;animation=disco&amp;background=transparent&amp;outline_width=0" alt="対象" height="24" align="absmiddle">の選定と長さ<img src="https://mojiemoji.jozo.beer/emoji/%E4%B8%8A%E9%99%90?font=maru-bold&amp;color=8b5cf6&amp;animation=ekken&amp;background=transparent&amp;outline=f68b5c&amp;outline_width=2" alt="上限" height="24" align="absmiddle"> を<img src="https://mojiemoji.jozo.beer/emoji/%E5%8F%82%E7%85%A7?font=toge&amp;color=a855f7&amp;animation=yokomoya&amp;background=transparent&amp;outline=f7a855&amp;outline_width=2" alt="参照" height="24" align="absmiddle">。
