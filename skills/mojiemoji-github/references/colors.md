## outline は `darker` / `triadic`、`ffffff` は<img src="https://mojiemoji.jozo.beer/emoji/%E7%A6%81%E6%AD%A2?font=maru&amp;color=8b5cf6&amp;animation=nami&amp;background=transparent&amp;outline=f68b5c&amp;outline_width=2" alt="禁止" height="24" align="absmiddle">

`outline=ffffff`(白アウトライン)は Tailwind 300–400 のライトな塗りに重ねると letterform の縁が消える。body-class surface の<img src="https://mojiemoji.jozo.beer/emoji/%E6%8E%A8%E5%A5%A8?font=mincho&amp;color=eab308&amp;animation=mabataki&amp;background=transparent&amp;outline=08eab3&amp;outline_width=2" alt="推奨" height="24" align="absmiddle">デフォルトは `outline=darker outline_width=2`(または `triadic`、parameters.md § outline <img src="https://mojiemoji.jozo.beer/emoji/%E5%8F%82%E7%85%A7?font=pixel&amp;color=60a5fa&amp;animation=zanzo&amp;background=transparent&amp;outline=fa60a5&amp;outline_width=2" alt="参照" height="24" align="absmiddle">)。

color-shifting 系 animation (`disco` / `psycho` / `kira`) は **outline 無し / `outline_width=0`** を catalog で持つ。テンプレ通りに `outline=...&outline_width=2` を埋めると hook で reject されるので、catalog variant の params を字面通り写すこと。

## 色の多様性 — 単色本文は #166 アンチパターン

本文<img src="https://mojiemoji.jozo.beer/emoji/%E5%85%A8%E4%BD%93?font=noto&amp;color=fdba74&amp;animation=mozaiku&amp;background=transparent&amp;outline=74fdba&amp;outline_width=2" alt="全体" height="24" align="absmiddle">で **4 種以上の hex 値**を使うこと。同色 15 スタンプは issue #166 の典型的な anti-pattern(全 stamp `60a5fa` でレビュアーから「単調」と指摘された実例)。selector subagent の Hard contract に `Color: 4+ distinct hex values across the body` を含めて enforce する。
